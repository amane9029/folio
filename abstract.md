# Folio Abstract

Folio is an internal EPUB library manager designed for private team use. It combines invite-only authentication, reader and administrator dashboards, EPUB upload and metadata extraction, cover handling, and AI-assisted title translation in a compact web interface tailored to internal library workflows.

Readers use Folio to upload and organize their own EPUB collections, search and sort titles, open book details, translate non-English titles, and delete books through an explicit confirmation flow. Administrators use a separate dashboard to review the shared library, search across contributors, manage invites, inspect the current frontend audit log, and remove records when needed.

The system is built with Next.js, TypeScript, Tailwind CSS, and InsForge for authentication, database access, storage, and AI features. Folio emphasizes secure access control, simple library operations, and a focused internal-tool experience rather than public discovery or content consumption.
